# Sinais do Universo — Museu Digital Ultra-Realista

Projeto em HTML5, CSS3 e JavaScript puro.

## Estrutura
- `index.html` — entrada cinematográfica
- `pages/museu.html` — Acervo Observável
- `pages/sistema-solar.html` — Sistema Solar interativo
- `pages/universo.html` — escalas cósmicas
- `pages/exploracao.html` — linha do tempo de missões
- `pages/fenomenos.html` — enciclopédia visual
- `pages/laboratorio.html` — simuladores
- `pages/glossario.html` — glossário pesquisável
- `css/main.css` — sistema visual responsivo
- `css/realism.css` — camada visual complementar
- `js/data.js` — dados do projeto
- `js/main.js` — interações e componentes

## Como abrir
Abra `index.html` diretamente no navegador ou use o Live Server do VS Code.

## Observação
O Sistema Solar usa renderização CSS/JavaScript para reduzir dependência de texturas externas. O Acervo Observável utiliza imagens científicas externas quando disponíveis e possui fallback visual para falhas de carregamento.
